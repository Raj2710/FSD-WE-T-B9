# Social Media App

# Feature Scope
1. Users Signup - SignUp
2. Users Login - Login
3. Users shall be able to post a feed and send for approval - CreateBlog
4. Admin has to review and approve the same - ViewBlog
5. Users can see others post as well - Feeds
6. Users shall check their post status that were sent for approval - Dashboard/My Blogs
7. Users or Admin can make a post Active or Inactive - ViewBlog
8. Users shall Like others post(optional feature) - Feed
9. Admin should be able to manage the users(Restrict/Delete user) - AllUsers
