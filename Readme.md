# Initialize a Express Project

1. Create a root folder for your project
2. Open the folder in VS code and open the terminal
3. Give npm init - to initiate the package.json file
4. Give npm i express - to install express
5. Create index.js and add necessary scripts to package.json
    For example: "start":"node index.js"
6. Code your own way by creating routes and functions.

Add express.json() middleware to gain access to Req body
Add cors() middleware to enable accessing endpoints from different origin
