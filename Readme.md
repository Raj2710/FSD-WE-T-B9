# Social Media App

# Feature Scope
1. Users Signup
2. Users Login
3. Users shall be able to post a feed and send for approval
4. Admin has to review and approve the same
5. Users can see others post as well
6. Users shall check their post status that were sent for approval
7. Users or Admin can make a post Active or Inactive
8. Users shall Like others post(optional feature)
9. Admin should be able to manage the users(Restrict/Delete user)
